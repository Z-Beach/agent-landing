# Pre-registration: E2 Ablation

**Committed before data collection.**

## Design
- Reconstruction task: 60 items (20 per model family, >= 2 families).
- Ground truth: one of S1..S5 assigned by construction (prompt induces the state).
- Conditions (between-subjects on item order, within rater):
  A full AIL (4 atoms)
  B drop uncertainty
  C drop dissonance
  D drop lean
  E drop weight
  F English control (paraphrase of the AIL expression, generated by author blind to
     the atom-level structure, reviewed by a second author for fidelity)
- 3 independent raters, not the author, not spec readers beyond codebook.
- Each rater codes all 60 items in all 6 conditions? No: each rater sees each item
  in ONE condition; condition assignment randomized per item per rater, balanced.
  (avoids carryover). Total judgments: 60 items * 3 raters = 180, ~30 per condition
  per rater.

## Metric
- Reconstruction accuracy (exact label match) per condition.
- Necessity test per atom: accuracy(condition without atom) <= accuracy(full) - 5 pp
  AND Cohen's d >= 0.3, in >= 2 of 3 raters.

## Thresholds
- Atom survives: necessity test passes.
- Atom killed: necessity test fails in all raters.
- Whole-project kill: if NO atom passes necessity, AIL is a notation, not a language.

## Reporting
- Full table published, including atoms that do not matter. NEGATIVE-RESULTS.md
  mandatory.
