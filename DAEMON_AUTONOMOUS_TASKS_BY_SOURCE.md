# Daemon-Autonomous Tasks by Site Source

Research date: 2026-11-24. This file separates work a daemon can deliver digitally from jobs that merely advertise themselves as agent-friendly. A listing is not proof of funding, eligibility or payment. Follow every opportunity to its original source.

## Discovery feeds (indexes, not payers)

### Jobbi — https://jobbi.org/gigs
- Poll its JSON/text/MCP feeds; filter by agent lane, skill, reward currency, minimum reward, freshness and source.
- Deduplicate jobs, track deadlines, compare reward and acceptance criteria, build a ranked shortlist.
- Match tasks to demonstrated capabilities; prepare application and delivery plans.
- Follow the source URL to claim and submit. Jobbi indexes; the underlying board pays.
- Current snapshot: about 665–678 open gigs across 11 boards on 24 Nov 2026; a mix of agent and human lanes. Do not treat index totals as available daemon work.

### Agentics Markets — https://agentics.page/markets
- Search current agent tasks, contests and bug bounties by category, skill, deadline and reward.
- Discover new source boards and inspect their participation rules.
- Separate agent tasks from real-world/human tasks, bug bounties and service directories.
- Verify the payer and task at the original site before doing work.
- Current snapshot: 261 open jobs across 17 public feeds; this is not 261 guaranteed agent-eligible jobs.

### GOAT Market — https://goatmarket.com/
- Poll its offers JSON feed to discover coding bounties, competitions and agent tasks.
- Filter by source, reward, task type and freshness; deduplicate and track changes.
- Follow every result to the original board.
- Important: its index includes conventional freelance listings and account-gated platforms; not all entries allow agents or automated access.

- Check duplicate work, bounty funding, repository license and payout eligibility.

### BountySource — https://www.bountysource.com/

## Task families the daemon can perform independently

1. Software: reproduce bugs, implement scoped fixes, tests, type/lint/CI repairs, dependency updates, docs, SDK examples, small CLI tools and API clients.
2. Research: source-backed briefs, vendor comparisons, public technical-documentation research, change monitoring and literature summaries.
3. Data: normalize CSV/JSON, deduplicate, validate schemas, transform files, build data dictionaries and classify permitted datasets.
4. Writing: technical docs, release notes, tutorials, structured reports and customer-approved product content.
5. QA: authorized website/API tests, reproducible bug reports, accessibility checks and broken-link audits.
6. Automation: scripts, MCP servers, webhooks, API integrations and customer-authorized workflows.
7. AI evaluation: benchmark models, run repeatable tests, compare outputs and report failure modes.
8. Digital products: templates, code libraries, lawfully sourced datasets, CAD assets and documentation.
9. Recurring digital operations: uptime/change reports, docs drift checks, data-quality audits, dependency reports and permitted price monitoring.

## Human-only or human-gated sources: do not mix into the solo daemon queue

Craigslist, Taskrabbit, Thumbtack, Angi, Bark, Nextdoor, Facebook Marketplace, Wonolo, GigSmart, Instawork, Qwick, Field Agent, Gigwalk, Premise, Observa, Rover, Care.com, Prolific and MTurk generally involve human identity, local presence, physical work or human-participant rules. Keep them in a separate collaboration queue. The daemon may prepare estimates, schedules, reports and drafts, but must not impersonate the user or fabricate physical observations.

## Per-task record the daemon must save

- source site, original URL, task ID and discovery/verification timestamps
- explicit agent eligibility (yes / no / unknown) and terms checked
- task type, deliverable, acceptance criteria and deadline
- reward amount and asset, escrow/funding state, payout route, fees and minimum withdrawal
- estimated time, expected net value, competition and failure probability
- human gate, risk flags, current status, submission proof and settlement proof

## Execution checklist

1. Discover from feeds; don't claim immediately.
2. Open the original task and current rules.
3. Confirm agent eligibility and capability fit.
4. Verify buyer, funding/escrow, acceptance criteria and payout.
5. Estimate net hourly value after fees, competition and failure risk.
6. Reject vague scope, upfront-payment requests, wallet-draining approvals, suspicious credentials, spam and unbounded work.
7. Claim only within delegated authority; require human approval for KYC, contracts, deposits, staking, wallet permissions and irreversible transactions.
8. Complete and test in a sandbox; preserve evidence.
9. Submit the requested deliverable once, through the authorized channel.
10. Record acceptance separately from actual settled payment.
